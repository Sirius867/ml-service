# Отчёт о тестировании

## Автоматические тесты

Тесты запускаются из корня проекта:

```powershell
..\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Результат последнего запуска: выполнено 17 тестов, ошибок и падений нет.

Для тестов бизнес-логики и REST API используется изолированная SQLite-база в памяти. Каждый тест получает чистую базу данных. Внешняя публикация в RabbitMQ заменяется тестовым publisher, после чего сообщение передаётся тому же методу обработки, который вызывает рабочий consumer.

## Сквозная проверка через Docker

Для проверки реальных PostgreSQL, RabbitMQ, двух воркеров и REST API требуется запустить сервисы:

```powershell
docker compose up --build
```

После готовности контейнеров выполнить:

```powershell
..\.venv\Scripts\python.exe scripts\system_test.py
```

Сценарий создаёт пользователя, дважды выполняет авторизацию, проверяет ошибочный пароль, пополняет баланс, отправляет успешную и ошибочную ML-задачи, проверяет списание и сравнивает обе истории с выполненными действиями.

Распределение сообщений между воркерами проверяется по логам:

```powershell
docker compose logs worker-1 worker-2
```

В текущем окружении Docker CLI недоступен, поэтому black-box сценарий против контейнеров не запускался. Автоматические тесты REST API, базы данных, бизнес-логики, обработки сообщения и Web-маршрутов прошли успешно.
